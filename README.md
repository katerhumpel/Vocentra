# Vocentra

**AI Speech Processing Studio**

Vocentra ist eine professionelle Windows-Anwendung zur automatischen Transkription, Übersetzung, Analyse und Nachbearbeitung von Audio- und Videodateien.

## Funktionen

- Automatische Transkription mit Whisper
- KI-gestützte sprachliche Nachbearbeitung
- Übersetzungen in zahlreiche Sprachen
- Zusammenfassungen und Analysen
- Lokale KI über Ollama
- Cloud-KI über Google Gemini und Groq
- Professionelle DOCX- und PDF-Berichte
- Komfortable Profilverwaltung über das Vocentra Configuration Studio

## Download

Die aktuelle Version von Vocentra steht im Bereich **Releases** zum Download bereit.

## Lizenz

Vocentra ist kommerzielle Software mit einer kostenlosen 14-Tage-Testphase.

Nach der Installation kann das Programm **14 Tage kostenlos getestet** werden. Für die weitere Nutzung ist eine gültige Lizenz erforderlich.

## Systemvoraussetzungen

- Windows 10 oder Windows 11 (64 Bit)
- Mindestens 8 GB RAM empfohlen
- Internetverbindung für Cloud-KI und Online-Videos
- Ollama optional für lokale KI-Verarbeitung
